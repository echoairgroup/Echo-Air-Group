Import items from JSON

Import up to 50 items at once. Use image URLs for bulk imports; upload local pictures from Add item.

The file can contain an array of items or an object with an items array. Each item can use title, description, category, targetPage, linkUrl, imageUrl and published.
{
  "items": [
    {
      "title": "New route announced",
      "description": "We have added a new route to our network.",
      "category": "route",
      "targetPage": "routes.html",
      "linkUrl": "routes.html",
      "imageUrl": "https://example.com/route.webp",
      "published": true
    }
  ]
}

Route network management

Routes are added automatically when NewSky flight history contains a completed flight. Archive a route to move it out of the public active list; the flight records remain in the database. Restore it whenever it becomes part of the network again.

This catalogue is based on actual recorded Echo flights, not NewSky's planned schedules. Archived routes remain visible on the public Routes page under the Archived filter.
